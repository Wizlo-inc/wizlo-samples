# Form Webhooks

Receives **`forms.*`** events from Wizlo. Triggered at every stage of a patient intake form session.

## What it does

When a patient interacts with a Wizlo intake form, events fire at each lifecycle stage. This sample lets you choose which event to subscribe to and displays received form events in a live frontend.

## Supported events

| Event | Triggered when |
|-------|---------------|
| `session_started` | Patient opens and starts the form |
| `progress_saved` | Patient saves progress mid-form |
| `completed` | Patient submits the completed form |
| `product_selected` | Patient selects a product during the form |
| `coupon_used` | Patient applies a coupon code |
| `disqualified` | Patient is disqualified based on form answers |
| `abandoned` | Patient exits without completing the form |
| `encounter_completed` | Payment completed and encounter successfully created |

## Ports

| Service  | Port |
|----------|------|
| Backend  | 3047 |
| Frontend | 3057 |

## Setup

**1. Create the `.env` file in `backend/`:**
```
WIZLO_BASE_URL=https://api-uat.wizlo.com
WIZLO_CLIENT_ID=your_client_id
WIZLO_CLIENT_SECRET=your_client_secret
WEBHOOK_SECRET=
WEBHOOK_SIGNING_HEADER=x-webhook-signature
PORT=3047
```

**2. Install and run the backend:**
```bash
cd backend
npm install
npm run dev
```

**3. Install and run the frontend:**
```bash
cd frontend
npm install
npm run dev
```

**4. Start ngrok:**
```bash
ngrok http 3047
```

## Steps to test

1. Open `http://localhost:3057` in your browser
2. Select the form event you want to listen for (e.g. `session_started`)
3. Paste your ngrok URL in the **Public Webhook URL** field:
   ```
   https://xxxx.ngrok-free.app/webhook/receive
   ```
4. Click **Register Webhook** — confirm success response
5. Log into Wizlo UAT and start filling out a patient intake form
6. Perform the action matching your chosen event (start, save, submit, etc.)
7. The event appears in **Received Events** within 3 seconds

## Event payload example

```json
{
  "event": "forms.completed",
  "data": {
    "form_name": "GLP-1 Intake Form",
    "session_id": "sess_abc123",
    "completed_at": "2026-05-21T10:30:00.000Z"
  }
}
```

## `encounter_completed` payload

Unlike other form events (whose fields live inside `data`), this event's fields are at the top level:

```json
{
  "event": "forms.encounter.completed",
  "form_id": "a241ea9a-1f98-42d9-812f-93e1b5323dd2",
  "form_name": "Checkout Form",
  "submission_id": "c7aa04b0-425c-495e-bf24-7e78136444e6",
  "patient_id": "d840a2bb-9b54-47b1-a2c6-5d5c48d8eab3",
  "order_id": "686337f4-6514-43ad-b780-944c7f3eb004",
  "encounter_id": "13",
  "submitted_at": "2026-06-01T18:49:45.959Z",
  "data": {
    "phi_first_name": "John",
    "phi_last_name": "Doe",
    "phi_email": "john.doe@example.com",
    "product_listing_eebf5d1f-36f4-4f7e-a836-39770f4b5fa5": [
      {
        "type": "PRODUCT",
        "productId": "91b57eba-9a1c-4542-86ce-e58e3dd9f13d",
        "unitPrice": 199.99,
        "productName": "NAD+ 500mg",
        "requiresLabs": false,
        "shippingType": "FREE_SHIPPING",
        "encounterMode": "ASYNCHRONOUS",
        "productOfferId": "20333744-f35a-4664-ba31-21f4671af12f",
        "shippingAmount": 0,
        "collectionMethods": [],
        "isEncounterRequired": true,
        "productEncounterType": "STANDARD"
      }
    ]
  },
  "external_order_identifier": "TEST-ORDER-001"
}
```

**Key payload fields:**

| Field | Type | Description |
|-------|------|-------------|
| `form_id` | UUID | Unique identifier of the form |
| `form_name` | string | Display name of the form |
| `submission_id` | UUID | Unique identifier of the form submission |
| `patient_id` | UUID | Patient who submitted the form |
| `order_id` | UUID | Order generated by this submission |
| `encounter_id` | string | Identifier of the created encounter |
| `submitted_at` | ISO 8601 | UTC timestamp of form submission |
| `data` | object | Key-value map of form responses (PHI fields prefixed `phi_`, product selections keyed by `product_listing_<uuid>`) |
| `external_order_identifier` | string | External ID passed via the embed link (see below) |

## Form embed link query parameters

Two optional query parameters can be appended to any form embed link to control session state and correlate submissions with external records.

| Parameter | Type | Description |
|-----------|------|-------------|
| `clearSession` | boolean | When `true`, clears the current session on every load — ensures a fresh session per user or order flow |
| `externalOrderIdentifier` | string | Arbitrary ID from your system (e.g. order number). Stored with the submission and returned in the `encounter_completed` webhook payload |

**Example:**
```
<INITIAL_FORM_LINK>&clearSession=true&externalOrderIdentifier=TEST-ORDER-001
```

`clearSession` controls session state at load time. `externalOrderIdentifier` travels with the submission through to the webhook payload — they operate independently and can be combined.
